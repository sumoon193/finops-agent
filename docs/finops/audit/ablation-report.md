# FO-13 检索消融与发布审计报告

## 方法

本报告按冻结集（frozen set）评估检索收益，核对发布门槛，并如实列出未验证项（unverified）。冻结集包含 RLS 阻断、AST 门禁与查询正确率三类用例，结果由离线 fixture 计算，确定性可复现。

## 检索收益

- 基线准确率：冻结集上未启用检索增强的实现准确率。
- 消融后准确率：启用检索增强后同一冻结集上的准确率。
- 检索收益 = 消融后准确率 - 基线准确率，按冻结集逐用例计算，收益结果与冻结集版本绑定。

## 发布门槛

- 所有模块构建完成并通过合同测试（module-contracts）。
- 全回归 `pytest tests/finops` 通过；秘密扫描与测试完整性门禁通过。
- 主集成模型的合并、跨模块优化与最终 Bug 修复未执行前，不对外宣称可发布。

## 未验证项（unverified）

- 真实模型收益未验证：模型默认 blocked，只有 Recorded fixture 可测量，因此本报告不声称模型收益已验证。
- 真实数据库 RLS 未在真实服务上验证，仅离线镜像语义。
- 真实外部服务（云账单来源、工单系统）未连接。
- 远端分支保护未配置（remote_protection=unverified）。
